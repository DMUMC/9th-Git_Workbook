# Git이란?

- 파일의 변경 사항을 추적하고 여러 사용자 간에 해당 파일들의 작업들을 조율하기 위한 분산 버전 관리 시스템 
- 
---

## 분산 버전 관리 시스템
- 중앙에서 관리되는 하나의 저장소를 모든 사용자가 복사하여 각자의 컴퓨터에서 작업하고, 작업 결과를 중앙 저장소에 반영하는 시스템

> 간단하게 말하면 여러 명이 독립적으로 작업하고, 각자의 수정 기록을 추적하여 협업할 수 있도록 돕는 시스템
---

## 버전(Version) 관리

- Git에서는 파일의 변경 시점을 버전이라고 부름
- 파일을 수정하고 커밋(commit)을 통해 그 변경 사항을 버전으로 기록하고 추적
- 각 버전은 고유한 커밋 ID로 관리되어 어떤 변경이 있었는지 언제든지 확인 가능

---

## 파일 관리 방법

- Git은 단일 파일뿐 아니라 여러 파일을 동시에 관리할 수 있도록, 저장소(repository)라는 개념 사용
  - 저장소는 작업하는 파일들이 저장되는 폴더처럼 이해하쇼
  - Git 저장소는 로컬 저장소(local repository)와 원격 저장소(remote repository)로 나뉨
    - 로컬 저장소: 사용자의 컴퓨터에 저장되는 Git 저장소
    - 원격 저장소: GitHub, GitLab 등 클라우드에서 관리되는 저장소
  - Git은 로컬 저장소**에서 작업을 하고, 원격 저장소와 동기화하여 협업합니다.
