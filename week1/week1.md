### 왜 TypeScript인가

-   정적 타입 검사로 오류를 사전에 차단하고 생산성과 협업 효율을 높일 수 있다.

### 기본 타입

-   string, number, boolean, null, undefined, symbol, bigint, object의 의미와 예시를 실습했다.
-   null은 의도적 부재, undefined는 미할당이며 각 특성과 타입 차이를 구분했다.

### 함수 타이핑

-   매개변수와 반환 타입 표기법을 익히고 선언식/화살표 함수의 특성과 this/호이스팅 차이를 정리했다.
-   유니언 인자 처리 시 typeof/instanceof로 타입 좁히기를 적용했다.

### 리터럴/객체/불변

-   문자열·숫자·불리언 리터럴 타입으로 값 범위를 제한했다.
-   객체 리터럴 타입, 선택적 프로퍼티, 인덱스 시그니처를 사용했고 as const와 readonly로 불변과 좁은 타입을 보장했다.

### 배열과 튜플

-   배열은 T[]/Array<T> 두 표기법을 학습했고, 인덱스 존재 보장에 튜플을 활용했다.
-   튜플의 push/pop 허용 이슈를 readonly 튜플로 해결했다.

### 유니언과 좁히기

-   A | B 형태로 유연성을 확보하고, 분기 로직에서 타입 좁히기로 안전하게 처리했다.

### TS 전용 타입

-   any(최대 유연성), unknown(검사 후 사용), void(반환 없음), never(도달 불가) 사용처를 실습했다.

### 타입 재사용

-   타입 별칭과 인터페이스 병합, 네임스페이스 병합 특성과 주의점(의도치 않은 병합)을 학습했다.

### 제네릭

-   제네릭 함수의 선언/호출 패턴과 타입 변수 전파로 유연성과 타입 안정성을 동시에 확보했다.

### Enum

-   숫자/문자열 enum, const enum, 숫자 enum의 양방향 매핑과 사용 장점을 정리했다.

### 유틸리티 타입

-   Pick, Omit, Record로 필드 선택/제거/키-값 매핑을 구성했다.
-   Partial/Required/Readonly로 선택성·필수화·읽기 전용화를 적용했다.
-   Exclude/Extract/NonNullable로 유니언을 정제했고, ReturnType/Parameters로 함수 타입을 자동 추출했다.
