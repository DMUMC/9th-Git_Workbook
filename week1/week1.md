-   이해한 점: 이번 실습을 통해 자바스크립트와 타입스크립트의 차이를 명확히 이해했습니다. 데이터를 다룰 때 type을 명시하는 타입스크립트가 왜 필요한지, 그리고 이를 통해 코드가 얼마나 안정적으로 바뀌는지 직접 경험할 수 있었습니다. 또한, add, complete, delete와 같은 함수들을 통해 투두리스트의 전체 로직이 어떻게 구성되는지 파악하며 프로그래밍 흐름을 익혔습니다.
-   어려운 점: 자바스크립트에 대한 기초 이해가 부족해 함수들의 호출 순서나 변수들의 논리적 흐름을 파악하는 데 어려움을 겪었습니다. 특히, 데이터를 수정하고 나서도 화면이 바로 업데이트되지 않는 문제가 반복적으로 발생했습니다. 영상 강의를 반복해서 보며 문제를 해결했고, 데이터가 변경될 때마다 renderTasks 함수를 호출하여 UI 상태를 동기화하는 방법을 깨닫게 되었습니다.
-   회고: 이번 워크북을 통해 코드로 웹 페이지의 요소를 동적으로 만들고 조작하는 DOM 활용법을 익힐 수 있었습니다. 특히, createElement()나 appendChild()와 같은 메서드를 직접 사용해 UI를 그리는 과정이 유익했습니다. 또한, type을 정의하고 타입을 명시하여 버그를 사전에 방지할 수 있음을 알게 되어 좋았습니다. 추가적으로 투두리스트의 로직을 이해할 수 있게 되었습니다.
